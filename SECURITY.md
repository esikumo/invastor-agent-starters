# Security

Do not report credentials or exploitable security details in a public issue.
Use GitHub's private vulnerability reporting if available on this repository.
If unavailable, use the private support channel linked from
https://invastor.com and request a private security contact before sending details.

If a credential has been exposed, revoke it through its provider immediately.
Deleting a file or commit does not revoke a credential.

The sandbox uses fictional inventory and simulated funds. Live agent authority,
wallet signing and funding are separate. A failed or timed-out write may have
succeeded: preserve the original purchase identity and private journal and
reconcile status. Never blindly create a replacement order or payment.

Connection stores may contain plaintext credentials protected by OS permissions;
use private persistent storage, not a shared folder or web root. One worker per
connection unless you implement a supported distributed storage/locking adapter.
